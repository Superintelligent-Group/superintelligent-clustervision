# Command reference

Every command and every argument `cv` has, generated when this manual is built from
`cv schema --commands --json` — clap's own reading of the binary's command tree. Nothing here is
typed by hand, so nothing here can be stale: a new flag appears the day it is added. The other
chapters say what the commands are *for*; `cv <cmd> --help` says the same as this page.
